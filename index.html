About Me

I'm a machine learning and software engineer who enjoys building reliable systems around complex data. At Canva, I worked on production generative AI infrastructure; at Torc Robotics, on large-scale autonomous-driving data platforms; and at Bosch, on computer vision and intelligent optimisation.

My work spans architecture, distributed processing, model serving, data engineering and production operations. I am particularly interested in reliability, scalability and the trade-offs between performance and cost. My PhD focused on nonlinear system identification and uncertainty-aware time-series prediction.

Data Engineering E2E: Fraud Detection Project

This project demonstrates a data pipeline for processing, analyzing, and publishing fraud detection data. The pipeline integrates multiple modern data engineering tools and technologies to handle data generation, ingestion, transformation, and quality checks, ultimately publishing the results as data marts in snowflake dataware house.

Data Engineering E2E: Retail Project

This project demonstrates the creation of an end-to-end data pipeline using Apache Airflow, BigQuery, dbt, Soda, and the Astro SDK. It showcases a robust pipeline that uploads retail data to Google Cloud Storage, ingests it into BigQuery, performs transformations using dbt, and ensures data quality using Soda.

Python Data Viz: Superstore Dashboard - Streamlit App

This project contains a Streamlit application designed to visualize and analyze Superstore data. It uses the MVC design pattern (Model View Controller). The dashboard provides interactive charts, filters, and insights into sales, profits, and other key metrics.

Data Engineering E2e: Real Time Data Streaming - Using: Kafka, PySpark, Cassandar, Airflow and docker

This project focuses on building a real-time data streaming pipeline, encompassing all phases from data ingestion to processing and storage.
